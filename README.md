## 2026_05_20_gdp_roll_pitch_yaw

### Setup

Clone this repository into an existing project that is **not already a Git repository**:

```bash
git clone https://github.com/EloiStree/2026_05_20_gdp_roll_pitch_yaw.git addons/2026_05_20_gdp_roll_pitch_yaw
```

This project contains student exercises focused on implementing **Yaw, Pitch, and Roll rotations** to practice trigonometry and object relocalization in Godot.

<img width="1280" height="738" alt="image" src="https://github.com/user-attachments/assets/6a4f6a37-a743-4e33-bacb-47869e70f3d7" />

Included are two example implementations:

* A classroom example where we relocated an object, then computed **Yaw, Pitch, and Roll** values and connected them to joystick input.
* A provided example using a **Node3D Quaternion** approach to generate **Pitch and Roll** values with joystick controls.

A small car controller is also included. It takes a **Vector2 joystick input**, allowing you to test and experiment with your implementation.

This is **not an XR toolbox**, but it was designed to be tested and used in **XR environments**.
